# Initiative Timeline Turn Manager

**Date:** 2026-08-24  
**Difficulty:** Intermediate  
**Estimated time:** 55 minutes

## Brief

Create a deterministic turn timeline where speed affects action frequency and characters can delay or be inserted mid-combat.

## Requirements

- Faster characters must generally act more frequently.
- Delaying a turn must preserve other characters' progress.
- Defeated characters must be removed safely.
- Adding a character must not reset the existing timeline.
- Tie-breaking behaviour must be deterministic.

## Additional constraint

Dependencies must be supplied through a constructor or explicit initialisation method.

## Stretch goal

Add a debug event history with a configurable maximum capacity.
